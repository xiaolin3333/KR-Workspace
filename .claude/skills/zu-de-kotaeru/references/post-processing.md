# 人に見せる前の整形チェックリスト

図はできた直後、たいてい「自分用」の状態になっている。人に渡す前に、以下を確認する。全部やる必要はなく、渡す相手を見て必要なものだけ足せばよい。

## 1. 1枚に収める
スクロールしないと全部見えない時点で、それはもう1枚ではない。
```
画面に一度で収まる大きさにしてください。収まらないなら要素を減らしてください。
```
減らせないものは無理に1枚にせず、2枚に割る（全体像用と詳細用など）。

## 2. 箱は名詞、矢印は動詞
箱の中に動きの説明まで詰め込むと文字が多くなり読みにくい。
```
箱の中は名詞だけにして、動きは矢印側に書いてください。
```

## 3. 色は2色まで
強調したい1色と、あとは全部グレーが基本。色数が増えるほど、どこが大事か分からなくなる。

## 4. タイトル1行＋結論1行を添える
図の上に「何の話の図か」を1行、下に「で結局どうなのか」を1行加える。この2行があると、口頭の補足なしで渡せる資料になる。

## 5. 個人名・社名・金額を伏せる
社外や他部署に出す前に必ず行う。
```
名前が入っている箇所を役割名に直してください。
```
図はスクリーンショットで一人歩きしやすいので、社内限定のつもりでも念のため実施する。

## 6. 声に出して説明できるか確認する
貼る前に、自分で一度声に出して図を説明してみる。説明できない箱が1つでもあれば、そこは中身を理解しないまま図にした箇所。消すか、その部分だけ内容を確認し直す。
