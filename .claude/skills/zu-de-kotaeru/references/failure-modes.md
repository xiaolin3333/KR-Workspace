# よくある崩れ方と対処

## 1. 情報を詰め込みすぎて、図の方が読めなくなる

長い文章をそのまま「図にして」と頼むと、書いてあることを全部拾おうとする。文章なら読み飛ばせた枝葉が、図では本筋と同じ大きさの箱として並び、迷路のような図になる。

**対処**: 出てきてから減らすのではなく、最初のプロンプトに上限を書き込む。
```
1枚に入れる要素は7つまで。収まらない分は重要な順に切って、切ったものは図の下に箇条書きで残してください。それでも必要なら2枚に分けて、1枚目は全体、2枚目は細かいほうにしてください。
```

## 2. 日本語のラベルが折り返されたり、はみ出したりする

箱の幅は英語基準で決まりがちで、長い日本語（とくに「〜における〜の実施」のような名詞句）を入れると崩れる。

**対処（2段階）**:
1. 最初のプロンプトで文字数上限を指定する。
   ```
   箱と矢印のラベルは1つ12文字以内。超えるものは短い名詞に言い換えて、助詞や「〜すること」は落としてください。
   ```
2. それでも崩れたら、全部を作り直させず、崩れた箇所だけ指摘する。
   ```
   文字がはみ出している箱があるので、その箱のラベルだけ8文字に縮めて出し直してください。
   ```

## 3. 毎回レイアウトが変わって、資料として揃わない

毎回ゼロから頼むと、そのときの回答内容に合わせて形が決まる。1枚ずつなら困らないが、週次報告のように並べて見せるものだと、揃っていないだけで雑に見える。

**対処**: 気に入った1枚をそのまま貼り付けて、型として固定する。
```
この形を基準に、中身だけ差し替えてください。箱の数・並べる向き・色の使い方は変えないでください。
```
使い回す型を2〜3個持っておけば、たいていの定例報告はそれで回る。
