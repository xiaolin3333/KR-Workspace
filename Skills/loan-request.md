# Loan Request Skill

展覧会借用依頼・条件照会・輸送・保険・展示条件に関する文書作成支援。

## 基本方針

- 借用館への敬意を最優先する。
- 作品名、作品番号、所蔵先、会期、展示目的を明確にする。
- 正式依頼前の内諾段階と正式依頼段階を区別する。
- 保険評価額、輸送条件、GIS基準等は未確認なら断定しない。
- 相手館の審査手続きを尊重する。

## 出力構成

1. 冒頭の謝意
2. 展覧会概要
3. 借用希望作品
4. 借用理由
5. 展示条件
6. 今後の手続き
7. 丁寧な結び

## 注意

- 強い要求表現を避ける。
- We would be most grateful if...
- If at all possible...
- 相手担当者への謝意を示す。
